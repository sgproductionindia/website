# Design Lock

The current SG Production website UI and layout are locked.

Deployment freeze: the current UI, layout, responsive behavior, player position, banner layout, footer spacing, and mobile navigation behavior are final for deployment. Do not adjust them during future fixes unless the site owner explicitly asks for that exact design change.

Do not change visual design, spacing, layout, colors, typography, responsive breakpoints, player alignment, banner sizing, footer spacing, navigation layout, card layout, or button styling unless a future request explicitly asks for a UI/design/layout change.

Allowed without changing the design:
- Backend fixes
- Data/API fixes
- Security fixes
- Copy/text updates requested by the site owner
- Bug fixes that preserve the current visual appearance
- Performance fixes that do not alter layout or styling

When changing code, preserve:
- Homepage carousel layout and sizing
- All Tracks grid layout
- Sticky bottom player layout and alignment
- Subscribe on YouTube section layout
- Footer spacing
- Mobile/tablet/desktop responsive behavior
- Admin panel layout and card styling

If a change could affect the UI, stop and confirm before editing.
